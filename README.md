Welcome to **GAME HUB** – a fun, interactive web game hub created for the **Creative IT Institute contest**. Explore mini-games, decorate your café, interact with cats, and enjoy animations! 🐱✨

---

## 🌟 Features

- **🐾 Interactive Cat Café Game**  
  Place decorations, feed cats, and watch them play in a cute virtual café environment.

- **🪴 Decoration System**  
  Add or remove plants, tables, mirrors, and other decorative items.

- **🏆 Level & Coin System**  
  Track your progress with coins and levels as you play.

- **💻 Responsive Design**  
  Optimized for screens **1280px and above**. Smaller screens show a stylish popup warning using **SweetAlert2**.

- **✨ SweetAlert2 Popups**  
  Elegant notifications for important game actions and alerts.

## 🛠️ How to Play

1. Open the [Live Demo](https://nadia-momo.github.io/GAME_HUB_Creative_it_institute/) in a web browser.  
2. Ensure your screen width is **1280px or larger**. Smaller devices will display a SweetAlert2 warning.  
3. Interact with cats, feed them, place decorations, and earn coins.  
4. Explore tables, plants, mirrors, and other interactive elements.
